# BlockNote (.block)

NAS4USB는 [BlockNote](https://www.blocknotejs.org/)를 npm 패키지로 사용합니다.

- `@blocknote/core`, `@blocknote/react`
- LAN 협업: Yjs `XmlFragment` (`blocknote`) + 기존 WebSocket room
- 파일 형식: `.block` (JSON, `format: "blocknote"`)

업데이트: `npm update @blocknote/core @blocknote/react` 또는 `npm run update:all`
