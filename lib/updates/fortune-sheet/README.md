# Fortune Sheet update package (optional)

USB 오프라인 환경에서 npm registry에 접속할 수 없을 때, 이 폴더에 Fortune Sheet npm 패키지를 미리 복사해 두면 **에디터 업데이트**가 npm 대신 이 경로를 사용합니다.

권장: 인터넷이 되는 PC에서 `npm install @fortune-sheet/react@latest` 후 `node_modules/@fortune-sheet` 내용을 이 폴더에 복사합니다.

정상적인 경우에는 `npm install`로 `@fortune-sheet/react`가 프로젝트 루트에 설치됩니다.
