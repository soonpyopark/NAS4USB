# TipTap HTML editor offline update

Copy vendored TipTap packages here for USB offline update, or rely on `npm install @tiptap/*@latest` via **에디터 업데이트**.

Primary packages: `@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/extension-table`, `@tiptap/extension-placeholder`.

TipTap v3 merges table sub-packages into `@tiptap/extension-table` (`Table`, `TableRow`, `TableCell`, `TableHeader`).
